# Changelog

## [1.2.12] - 2026-04-18

### Fixed
- Снижены микрофризы при установке/проверке мастер-пароля за счёт переноса bcrypt-операций из основного UI-потока.
- Уменьшены всплески задержки при частых операциях сохранения данных благодаря пакетной обработке write-операций.

## [0.2.11] - 2026-04-17

### Added
- Добавлен отдельный раздел «Хранилище» для сохранения логинов, паролей и заметок по сервисам.
- Добавлены удобные карточки записей хранилища с быстрым доступом к просмотру и редактированию.
- Добавлены новые формы и подтверждения действий в едином формате листов (sheet), чтобы работа с заметками и хранилищем ощущалась одинаково.

### Changed
- Обновлён общий интерфейс заметок и хранилища: экраны стали более цельными и визуально аккуратными.
- Улучшен поиск и фильтрация в рабочих экранах, чтобы быстрее находить нужные записи.
- Доработаны тексты интерфейса и локализация, включая сообщения и подписи новых экранов.

### Fixed
- Исправлено отображение прогресса загрузки обновления: ползунок и проценты теперь корректно обновляются во время загрузки.

## [0.2.10] - 2026-04-17

### Added
- Добавлено модальное окно «О приложении» в `NotesView` с отображением названия, версии и описания.
- В `bottomDock` добавлена отдельная кнопка для открытия окна «О приложении».
- Добавлены новые переводы для блока «О приложении» (RU/EN), включая подписи версии, описание и ссылку на GitHub.

### Changed
- Обновлена версия приложения до `0.2.10` и скорректирован стартовый размер окна (`940x700`) в `tauri.conf.json`.
- В `NotesView` упрощено создание и редактирование заметок: убрано ручное поле заголовка, заголовок выставляется автоматически.
- Поиск в `NotesView` теперь выполняется по содержимому заметки, а закрепленные заметки получили отдельный бейдж в карточке.
- Переработаны стили `NotesView`: карточки, модальные формы, состояние критичности, нижний dock и темная тема.
- `VaultView` приведен к единому паттерну модальных окон через `SheetModal` и визуально переработан (карточки, search-sheet, формы, подтверждение удаления).
- В `VaultView` упрощены действия с карточками: убраны отдельные сценарии reveal/copy, отображается только маскированный пароль.
- Обновлен workflow релиза: исправлен регистр имени релиза (`Flowmode`) и англоязычный fallback-текст при отсутствии секции версии в `CHANGELOG.md`.

### Fixed
- Исправлен расчет прогресса загрузки обновления в Tauri updater: добавлена нормализация chunk/cumulative значений, чтобы прогресс-бар отображался корректно на разных backend-реализациях.

## [0.2.9] - 2026-04-17

### Added
- Добавлен индикатор текущего активного слоя в нижней части экрана.

### Changed
- Переработано поведение закрытия окна: приложение скрывается в трей вместо сворачивания, с одноразовой подсказкой через системное уведомление.
- Обновлена логика показа окна из трея (восстановление окна, возврат в панель задач, фокус).
- Обновлены стили NotesView: улучшена анимация модалок, уменьшена минимальная высота модального листа и доработаны тёмные темы для статусных блоков.
- Обновлён набор иконок приложения для desktop/mobile платформ.
