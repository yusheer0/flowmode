## Как писать описание релиза

1. Перед выпуском обновите `src-tauri/tauri.conf.json` -> `version`.
2. Добавьте новую секцию в этот файл с тем же номером версии, например:

```md
## [0.2.3] - 2026-04-17

### Added
- Новая функция A

### Fixed
- Исправлен баг B
```

3. Создайте тег `v0.2.3` и отправьте в репозиторий.
4. GitHub Release автоматически возьмет текст из секции `## [0.2.3]`.

Если секция не найдена, workflow подставит fallback-текст.
